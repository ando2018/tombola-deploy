Généré le 18/10/2026 23:01:19

Prérequis sur le serveur : Node.js 22 ou plus, accès à une base MongoDB.

1. Copier tout ce dossier sur le serveur.
2. Créer le fichier .env à partir de .env.example :
     PORT, MONGO_URI, JWT_SECRET (long et aléatoire), SUPERADMIN_LOGIN, SUPERADMIN_PASSWORD
   Important : garder le même JWT_SECRET (ou TOKEN_SECRET) que l'installation précédente,
   sinon les jetons d'abonnement existants ne pourront plus être copiés depuis l'admin.
3. Installer les dépendances (si node_modules/ n'est pas déjà présent) :
     npm ci --omit=dev
4. Démarrer :
     npm start
   ou, avec pm2 (redémarrage automatique) :
     pm2 start ecosystem.config.cjs
     pm2 save
   L'application (API + interface) est servie sur le même port : http://serveur:PORT

En production, mettre NODE_ENV=production et placer l'application derrière HTTPS
(le cookie du jeton d'abonnement n'est alors envoyé qu'en HTTPS).
Ne pas lancer « npm run seed » sur une base en production : il réinitialise l'organisation de démo.
